TITLE:
FastPointer: Ultra-Fast Native Address Arithmetic for Java 🚀

DESCRIPTION:
Demonstrating FastPointer, a zero-allocation primitive address abstraction for Java. It enables 64-bit native pointer arithmetic, direct memory dereferencing via Unsafe, and zero-copy data manipulation without heap allocation or GC pauses.

TECHNICAL HIGHLIGHTS:
- Primitive Long Wrapper: High-speed native address representation using 64-bit primitive values.
- Direct Memory Access: Ultra-fast Unsafe getters/setters for byte, int, float, and double types.
- Zero Allocation: Perform offset calculations and pointer shifts without creating Java objects.
- JNI Interoperability: Seamless bridge to C++ native code via FastCore.

RESULTS:
- Pointer Offset Math: 0 ns overhead (direct scalar arithmetic)
- Memory Access: Matches C++ raw memory dereferencing performance
